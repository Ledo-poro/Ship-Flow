# Project Flow

**Track your projects. Manage tasks. Share what you ship.**

Project Flow is a full-stack web application that helps solo developers and indie makers organize their side projects privately while giving them beautiful public pages to showcase their work.

## Features

- **Authentication** – Secure login with email and optional OAuth
- **Project Management** – Create, edit, and organize projects with status tracking
- **Task Management** – Break projects into tasks with priority and due dates
- **Public Showcase** – Share individual projects with clean public pages
- **Dashboard** – Overview of your progress and recent activity
- **Privacy Control** – Choose which projects are private or public
- **Responsive Design** – Works smoothly on desktop and mobile

## Tech Stack

- **Frontend:** Next.js 15 (App Router), TypeScript, Tailwind CSS
- **UI Components:** shadcn/ui
- **Backend:** Supabase (PostgreSQL, Auth, Storage)
- **Validation:** Zod
- **Deployment:** Vercel
